> 原则：框架代码（`apps/`、`packages/`）不动，所有行业改动集中在 `industry/`。分类 `key` 和主题 `slug` **公开上线后不能改**，所以内部试用阶段就是留给它们微调的窗口，试用复盘时冻结。
> 本文的分类、内容类型、评分维度均为**草案 v0.1**，需要业务对接人过一遍再落地。
> ✅ 进度（2026-09-29）：§1 站名（关务HOT）、§6 模块开关已完成；§3 信源 P0 前三条已接入；§2/§4（分类与提示词）待业务对接人确认草案后落地。

## 2. `industry/taxonomy.ts` —— 分类、标签、主体（草案 v0.1）

### 2.1 CATEGORIES（9 个，key 进网址，定稿前可调）

## 4. `industry/prompts/` —— 行业 KnowHow 所在（最值得花时间）

保留原结构（五维加权、噪声压制、安全边界、答案先行摘要），替换行业内容：

| 文件 | 改造要点 |
|---|---|
| `prefilter.md` | PASS=与进出口/报关/关务/国际物流/贸易合规明确相关；BLOCK=纯内贸、纯旅游签证、营销招聘；**BLOCK 必须有正面依据**；标题含"海关/关税/报关/退税/原产地"等明确行业词时，正文缺失可以 PASS |
| `selection-score.md` | 换内容类型权重表（见 §2.2 对应的 8 类）、重写五维语义与"必须正常评价/必须压住"清单（见下） |
| `content-understanding.md` / `understand.md` | 答案先行的摘要写法。**关务特有纪律**：摘要必须写清公告号、发布日期与**实施/生效日期**（两者不同是常态，漏写实施日期是行业大忌）；税率、品目号等数字照抄原文不换算；不解读法律后果，不替监管补全意图 |
| `rules-domain.md` | 关务术语表：HS 编码、两用物项、AEO、RCEP、原产地证、ETA/ETD、滞箱滞港费等怎么翻译/保留 |
| `rules-anti-hallucination.md` `rules-answer-first-summary.md` `rules-self-contained-title.md` `safety.md` | 结构保留，例子换成行业词 |
| `summarize-*.md`（6 个） | 保留结构，例子换行业 |
| `structure.md` | 事实帧语义换成"谁（机构/船公司）、做了什么（发布/调整/处罚）、对什么（税号/品类/口岸）"；主体从 ENTITIES 里选 |
| `group-*.md`（5 个） | 判断"是不是同一件事"的例子换成：同一公告的官网稿/媒体稿/公众号解读归为一组；不同税号的不同调整**不是**同一件事 |
| `story-digest.md` `report-daily-lead.md` `report-period.md` | 综述与日报导语的行业化：日报导语要突出"今天有什么会影响到申报动作" |
| `translate-*.md` `identity-context.md` | 结构保留，微调术语 |

**评分提示词的两个关键清单（草案，供业务对接人改）：**

必须正常评价的价值：
- 正式发布的新政/新规、税率调整、出口管制清单变化——即使条文平淡；
- 明确的实施日期与过渡期安排（deadline 就是价值）；
- 影响面大的口岸动态（主要港口、主要航线）与运价异动；
- 可直接照做的归类/退税/单证实务指南。

必须压住的噪声：
- 货代揽货广告、低价促销、公司开业庆典、招聘、会议预告（`sig ≤ 2`）；
- 无新事实的市场行情例行播报、转述旧政的"科普旧文"（`nov ≤ 3`）；
- 泛宏观经济评论但与进出口无关的；
- 培训课程软文、"某货代成功案例"类 PR（`sig ≤ 3`）。

## 5. `industry/selection.ts` —— 门槛（占位初值，必须校准后定）

```ts
export const SELECTION = {
  thresholds: { T1: 55, T1_5: 62, T2: 72 },
  understandFloor: 48,
} as const;
```

比 AI 行业默认值（60/65/76）略松，理由：关务领域"重要但平淡"的公告多，**内部试用阶段漏报的代价高于多报**（漏一条加税公告比多看三条噪声严重）。这组数只是起点，按 04 文档用 gold 样本校准后再定。
